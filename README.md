# OIBSIP – Data Science Internship Projects

## About the Internship

This repository contains the projects completed as part of the **Data Science Internship at Oasis Infobyte (OIBSIP)**. The projects demonstrate practical applications of Python, data analysis, data visualization, and machine learning.

## Projects

### Task 1: Iris Flower Classification
- **Objective:** Classify iris flowers into different species using their measurements.
- **Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.
- **Models:** Logistic Regression and K-Nearest Neighbors (KNN).
- **Evaluation:** Accuracy, precision, recall, F1-score, and confusion matrices.

### Task 2: Unemployment Analysis
- **Objective:** Analyze unemployment trends in India and compare unemployment rates across regions and time periods.
- **Tools:** Python, Pandas, Matplotlib, Seaborn.
- **Analysis:** Regional averages, monthly trends, correlation analysis, and pre-COVID versus COVID-period comparison.

### Task 5: Sales Prediction
- **Objective:** Predict product sales using advertising expenditure across TV, Radio, and Newspaper channels.
- **Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.
- **Models:** Linear Regression and Random Forest Regression.
- **Evaluation:** Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R² score.
