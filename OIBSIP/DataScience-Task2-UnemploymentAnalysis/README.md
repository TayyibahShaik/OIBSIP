# Task 2: Unemployment Analysis in India

## Project Overview
This project analyzes unemployment trends in India using data analysis and visualization techniques to explore changes over time and differences across regions.

## Objective
To examine regional unemployment rates, monthly trends, relationships between employment indicators, and differences between the pre-COVID and COVID periods in the dataset.

## Dataset
The dataset contains unemployment-related information, including region, date, estimated unemployment rate, estimated employed population, labour participation rate, and area.

**Dataset source:** [Unemployment in India — Kaggle](https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india)

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Project Workflow
1. Loaded and inspected the dataset.
2. Checked data types, missing values, and duplicate records.
3. Cleaned and prepared the data.
4. Compared average unemployment rates across regions.
5. Visualized monthly unemployment trends.
6. Compared trends across selected regions.
7. Created a correlation heatmap for unemployment, employment, and labour participation indicators.
8. Compared the pre-COVID period with the period beginning in March 2020.

## Key Findings
- Average unemployment rate before March 2020: **9.51%**
- Average unemployment rate from March 2020 onward: **17.77%**
- Difference: **8.26 percentage points**

The dataset shows a higher average unemployment rate during the period beginning in March 2020. This comparison alone does not establish that COVID-19 was the only cause.
